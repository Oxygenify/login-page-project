# Login/Signup Page
My first project i did just for fun and sharpening my front-end skills. It features simple log in page that you often found in websites.

## Features
This login page project has several features. The main one obviously being username and password inputs, login with 2 different apps, and sign up menu. Because this is just for fun project, I still didn't code the logic of the username and password handling, and login with app method. In the future, I might add those and probably add the main page in this project.

## Tech Stack
- **HTML5**: Semantic markup (`<section>`, `<button>`, and `hidden` attributes).
- **CSS3**: Layout styled with Flexbox and modern typography (Google Fonts - Outfit).
- **JavaScript (ES6)**: Vanilla DOM manipulation for interactive menu switching.
- **GitHub Copilot**: Used for refactoring and cleaning up. Also for script because I still don't really understand how JS works.
